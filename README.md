# INK／PLATE — SIX GRAPHIC PLATES

一套把六张「多色印刷 × 旧纸」海报**用纯矢量重新绘制**、以印刷机节奏编排成网页的作品集。

不是图片轮播：每张海报都被自动拆成 4–8 个矢量墨版，总计 **约 6,900 条平滑矢量路径**
（2048×3072 超采样追踪，二次曲线轮廓 + 32° 转角保护）。
切换进入一张海报时，整张纸先浮出一层极淡的「印前灰样」，随后 **4–7 个墨版按该角色专属的波次逐层压下**，
角色自己的动作矢量（拉满的弓弦、共振晶体、车轮与速度线、准星与弹道、刀光、轨道卫星）
以专属图形组成印刷锋面，随墨浪一起扫过纸面；约 1.3–1.7 秒后落定成一张完整的矢量画面。

```
ink-plates/
├─ index.html
├─ css/main.css
├─ js/plates.js     ← 六张海报的多墨版矢量分离数据（自动生成，约 3.6 MB）
├─ js/ink.js        ← 场景引擎：逐形状印刷、角色动作矢量、逐张转场
├─ js/app.js        ← 载入动画、印刷锋面、界面编排、交互
├─ assets/          ← 纸张颗粒、纤维、斑点（统一后处理贴图）
├─ source/          ← 原始海报（参考图；网页本身不加载任何海报位图）
└─ preview/         ← 成品截图（1920 / 390）
```

## 印刷时的入场动画（核心）

每一张海报的入场由四层同时进行，全部围绕「这张画正在被印出来」：

1. **形状级印刷**：每个矢量形状按「重心在波次方向上的投影」获得独立的落墨延迟，
   大块先落墨、细节后补上；未落墨处保留一层极淡的「印前灰样」。
2. **角色动作矢量**：入场期间，角色自己的动作在纸面上发生——
   爱莉希雅拉弓射出一支穿出画面的长箭与花瓣；爱弥斯的菱形共振环与生长晶体；
   布洛妮娅的速度线与旋转车轮；露娜的准星、弹道虚线与升起的天际线；
   琪亚娜贯穿画面的巨型刀光与火花；威龙的轨道椭圆与卫星。
3. **角色专属印刷锋面**：印刷波前面不是一个单纯的渐变条，而是由该角色的图案拼成——
   箭羽与花瓣组成的锋面、菱形共振环的锋面、速度线锋面、扫描线与准星锋面、
   刀锋与火花锋面、轨道弧与卫星锋面。锋面与印刷波同步扫过纸面。
4. **整幅画面入场**：每张海报有不同的起始位移/旋转（爱莉希雅斜落、布洛妮娅横向冲入、
   露娜自下升起、琪亚娜带旋转切入、威龙轴转、爱弥斯放大落定），
   配合细小的套印错位与最后一道柔光扫过。

切换时旧海报按**反向波次**逐块褪墨消失，新海报同时开始印刷，两套波次交叠——
这是元素变换，不是图片轮播。全程没有待机/循环动画；画面落定即静止。

## 性能：为什么现在是顺的

旧版把 1,000–2,700 个路径各自做成 CSS 动画，同时还在跑全屏纸纹动画，主线程被压垮。
现在：

- **每个墨版烘焙成一张 SVG 图像**：六张画共 42 张，全部由同一份矢量数据在运行时生成
  （Blob URL，不落盘、不加载位图），只在入场时使用。
- **印刷动画用一块 canvas 合成**：每帧只把「刚被墨浪推过的那几条窄带」画到 canvas 上，
  每帧开销约 1 次全屏拷贝 + 7 条窄带，而不是上千个元素的样式/布局计算。
- **落定后立刻销毁 canvas、显示矢量 SVG**，静止画面没有任何 canvas 参与。
- **纸纹动画全部改为静态**（原来 5 层全屏 `background-position` 动画，是主要卡顿源之一）。
- 每个墨版的路径在构建时合并成 **一条 path**，静态渲染的节点数从上千降到 4–7 个。

实测（Chrome headless，1440×900，软件光栅）：静止 16.7 ms/帧（60 fps），
入场期间中位 16.7 ms、p90 33 ms；真实 GPU 下应为稳定 60 fps。
`prefers-reduced-motion` 下跳过 canvas 印刷，直接显示成品。

## 矢量质量：从四色硬分版到多墨版追踪

- **2× 超采样追踪**：参考图先放大到 2048×3072 再分色、追轮廓，让发丝、睫毛、
  剑刃、天际线这类细结构获得足够的采样点。
- **平滑曲线轮廓**：轮廓在 Douglas–Peucker 之后转成二次贝塞尔（二次曲线经过每个顶点），
  并以 32° 转角阈值保留硬边——几何形保持锐利，人物曲线变得平滑，不再有锯齿状多边形边。
- **自适应色版**：中位切分给出候选色 → CIELAB 加权 K-means 聚类 → 按色差与人眼敏感度
  合并，得到每张 4–7 个真实墨版（例如 ELYSIA 是 蓝／深蓝／近黑／黑 四版）。
- **清理而非抹掉细节**：先剔除真正的抗锯齿细边（薄到只剩 1–2 px、覆盖率极低），
  再用连通域清理把噪点并入邻近墨版；只丢弃 < 1 px 的尘埃，保留细线。
- **自适应简化**：每个轮廓的 Douglas–Peucker 容差随面积变化（小细节 ~0.3 px，大色块 ~1 px）。
- **同色描边补缝 + 孔洞奇偶合并**：文字内孔、眼睛高光、镂空结构不丢。
- **统一纸感后处理**：纸张颗粒、云斑、纤维、暗角由页面统一叠加，不在矢量里重复绘制纹理。

## 十二个重点

1. **多墨版分离**：六张原图各自分离出 4–7 个墨版，全页画面 100% 由矢量路径实时绘制。
2. **逐版上墨**：每个墨版沿角色专属方向推进，锋面是锯齿油墨边；先有灰样，再有墨。
3. **六套印刷波次**：ELYSIA 斜向 34° 双波对扫；AEMEATH 以手部为圆心的径向晶化波；
   BRONYA 横向扫描；LUNA 由下而上的天际线波；KIANA 沿 52° 刀锋的双向波；
   VYRON 以轨道为轴的角向扫掠。每张的墨版交替反向，形成套印感。
4. **六套角色动作**：弓与箭、共振晶体、速度与车轮、准星与弹道、
   **琪亚娜的宽刃巨剑（剑身菱形宝石 + 蓝色火焰碎片 + 落点冲击环）**、轨道与卫星。
5. **六套角色专属印刷锋面**：入场时的波前由各角色的图案构成，随印刷同步前进。
6. **元素变换式转场**：旧画面逆波次褪墨，新画面同波次上墨，两套波次交叠。
7. **载入动画**：一次「开机印刷」——六格印版就位、状态与百分比滚动、套印偏移的
   SIX／PLATES 在套准中滑入，最后整张纸被掀起，露出正在印刷的第一张。
8. **套准错位**：标题、色块与动作线稿保留 1–2 px 蓝／墨错位；转场时色版先撞网再对齐。
9. **纸张后处理**：两套尺度的颗粒 + 云斑 + 纤维 + 暗角 + 灰尘构成统一后处理层。
10. **可玩细节**：鼠标倾斜与随指针移动的油墨反光；转场结尾的套准闪光与柔光扫过。
11. **响应式**：桌面为编辑排版（左编号 / 中海报 / 右信息），窄屏重排单列并保留全部动效。
12. **可访问性与零依赖**：`prefers-reduced-motion` 下缩短印刷、关闭粒子与倾斜；
    没有框架、没有构建、没有网络字体。

## 生成管线（可复现）

`source/` 中六张原图经以下步骤转成矢量：

1. 放大 1.5×（Lanczos）→ 中位切分候选色 → CIELAB 加权 K-means → 按色差合并 → 墨版；
2. 逐像素分类 → 条件多数平滑（只清除孤立噪声，保留 1 px 线）→
   剔除细抗锯齿边 → 连通域清理（< 32 px 的噪点并入邻版）；
3. 对每个墨版做像素边界追踪（边沿图 + 右转规则）→ 孔洞嵌套 → even-odd 路径；
4. 按面积自适应 Douglas–Peucker 简化 → 转角检测 → 二次贝塞尔平滑，输出绝对坐标曲线路径；
5. 坐标缩回 1024×1536 场景空间，生成 `js/plates.js`；
6. 纸张颗粒 / 云斑 / 纤维由 numpy 分形噪声生成。

> 矢量重绘会舍去原图的油画式微渐变，换来的是可逐版印刷、可无限缩放、可逐形状编排的印刷语言；
> 纸纹与油墨质感由统一后处理补足。

## 逐帧自检发现并修掉的问题

把六张海报的入场逐帧截图 + 资产单独导出检查后，发现并修复：

1. 标题层里混进了背景几何块（AEMEATH / BRONYA / KIANA / LUNA / ELYSIA 标题右侧的黑色楔形）。
   原因是被标题搜索框裁断的图案连通域也会被当成字块；现在"贴到搜索框边界"的连通域一律丢弃。
   同时放宽副标题的细笔画阈值，HONKAI IMPACT / WUTHERING WAVES 不再缺字母。
2. 标题动画开始得太早（印刷进度 30%），标题会浮在还没印出来的空白纸上。
   改为印刷 55% 后开始，落定时刚好完整。
3. 标题逐字入场顺序是描边顺序（乱的）。改为按字块包围盒 y → x 排序，按阅读顺序浮现。
4. LUNA 的窗格、VYRON 的轨道环/卫星等背景细节在印刷阶段就出现。改为创建时 opacity:0，落定才淡入。
5. ELYSIA 的弓把整只手/手臂一起带着飞。拆成 bowTop / heart / bowBottom 三段，手留在画面里。
6. KIANA 的剑把躯干和腿也带进来了。收成"剑柄 + 薄剑身"两段。
7. BRONYA 车轮抠得太小（只剩圈）。按原图半径放大到 r190 / r238。
8. 奶白色箭杆（ELYSIA / LUNA）和纸色相同，颜色分离会把它当背景丢掉，只留背景几何。
   试过对比色底、白底、亮底三种方案都无法稳定分离，因此改为：箭留在印刷底图里（仍是原图那支箭，
   不再出现错误的飞行块），弓件继续作为独立资产入场。

剩余已知：水晶/弓件与背后图案重叠，飞行中仍会带少量相邻图案；要完全干净需要逐像素手工蒙版。

- LUNA 的背景循环里删掉了常驻准星（lscan），准星只在入场 FX 中出现并在落定前消失。
- 六张图的 base 层重新生成：把全部物件区域从底图中挖掉后再描一次，物件不会在印刷阶段提前印出来。

**资产分离（全部来自原图）**

  入场时逐字错位浮现；按 `T` 可在 3 种“同一个标题”的动态方案间切换（升起 / 刮印 / 压印），样式始终不变。
- ELYSIA 箭：从原图箭杆与箭头位置单独抠出（26 个形状），入场时箭沿原方向滑入；删除了所有手绘箭。

**出场衔接**
- 切换时旧海报按自身方向整张滑出（位移 + 旋转 + 缩放，560ms 缓停），新海报延后 90ms 从同向进入，
  两段动画叠在一起；引导光带与收尾闪白同步衔接。

## 动画曲线与过渡（本轮重点）

整套动作从「到位即停」改成有呼吸的缓停：

- **物件入场**：不再是两帧直线位移。每个物件先轻微呼吸淡入、再沿一条缓入缓出的路径滑入，
  在 80% 处轻微越位（scale 1.004）后回落到原位；时长覆盖整段印刷，不再抢拍。
- **印刷推进**：每层墨版的显影进度用 smootherstep 曲线（慢起—加速—慢收），
  每层时长再乘一个 ±6% 的手工扰动，层与层保持交叠，不再像机械扫条。
- **画布交接**：印刷结束由「瞬间切换」改成 240ms 画布淡出 / 340ms 矢量淡入的重叠交接。
- **收尾层出现**：标题、残影、背景细节不再是突然冒出来，而是 560–640ms 的轻位移+淡入。
- **引导线**：横向光带改为慢起慢收并带中段停顿；环形/角向引导拆成多段缓动，去掉匀速旋转。
- **场景切换**：离场整张纸轻微上浮缩小（460ms 缓停），入场延后到 170ms 再开始，露出呼吸间隙。
- **UI 文案**：标题行、规格行、角标都改用多段缓动，落位时带 2% 回弹。
- **减少动效**：`prefers-reduced-motion` 下直接呈现最终画面（标题、物件、背景都在，无动画）。

核心自定义曲线：`glide / breath / settle / drift / calm`（见 `js/ink.js` 的 `EASE` 与 `smoothstep/smootherstep`）。

## 场景物件：入场资源就是海报里的原物

每张海报的关键物件不再用「贴上去的特效」表现，而是从原图里按区域单独追踪成物件层：
KIANA 巨剑、ELYSIA 弓、BRONYA 前后车轮、LUNA 天际线、VYRON 地球+空间站、AEMEATH 晶体。

入场播放时，物件层被它的**手绘轮廓 clipPath 裁成真实物件形状**飞入画面——
轮廓是逐张按 2× 放大裁切手工勾的：巨剑拆成「剑柄+剑身」两段轮廓、弓拆成「弓臂+心形饰品+箭线」三段、
车轮用精确圆、天际线沿屋顶阶梯、地球用圆、空间站与晶体沿外缘折线——
看到的是剑/弓/车轮/楼房/地球本身在移动，而不是一块方形画面；
落定瞬间解除裁剪，与底层画面完全重合。物件层本来就是从原图拆出的同一批矢量形状，
所以最终画面与参考图**逐像素一致**，没有接缝、也不会多出元素。

## 背景细节的独立动画（不出画框）

- 六张版面都有一组**小方块/几何形**在画框内做位移、旋转、缩放循环，每张位置与节奏不同；
- **LUNA**：楼房窗格逐格亮灭 + 准星环缓慢摆动；
- **VYRON**：地球轨道虚线、卫星小点在框内漂移、空间站灯光闪烁；
- **BRONYA**：侧向箭头滑动/放大；
- **ELYSIA**：花瓣缓慢漂移；
- **KIANA**：火星在框内浮动；
- **AEMEATH**：晶体反光点逐颗闪烁。

全部为非线性的 `ease-in-out / cubic-bezier` 循环；边界实测 0 个元素越界。

## 溢出、裁剪与物理脱落

- 入场过程中允许动作矢量越出画框；入场结束后 `scene-host` 立即 `overflow:hidden`，之后无元素溢出。
- 收尾时有 8 片「纸屑/墨片」在画框边缘受力下落、旋转淡出（物理化脱落），再锁定裁剪。

## 名字的三套重新设计（按 `T` 循环）

1. **INK ECHO**：黑色字 + 蓝色/米色错位复写 + 套准短线；
2. **DIAGONAL CUT**：整个名字沿斜线切开、两半错位，露出蓝/黑印层（不再是百叶窗横条）；
3. **OUTLINE + FRAME**：米色描边字 + 蓝色偏移投影 + 套准角标与虚线框。

直接作用在从原图追踪下来的真实字形上，不换字体覆盖。
